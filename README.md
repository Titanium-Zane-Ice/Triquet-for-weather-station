# Triquet-for-weather-station

This is a trinquet for the weather station. It is an anemometre whos rotor can spin. The rotor and the base are to be printed separatly but they do clisp into each other. the rotor has the flapy bits at the end that should bend inwards when they are pushed against the bits that stick out in the base tube. once that is passed the rotor should be able to spin and stay in position. Also I have put a Tolerance of 0.5 for the gap between the rotor and the base tube.
